# ロボットと、チャンバラ。

更新日：2026-09-22  
状態：展示企画案・原案反映版

## 提案

**「ロボットとチャンバラできた」を持ち帰る展示。**

音や光に合わせて、目の前のロボットの剣を自分の剣で受ける。相手がひるんだ隙に、光る弱点へ一撃。紙風船を守りながら、自分がロボットと対戦した手応えを楽しむ体験型展示を提案します。

## 来場者に体験してほしいこと

- **対戦相手がいる。** 自動で動くロボットに向き合い、自分の剣を合わせる。
- **自分の動きで展開が変わる。** 受けに成功すると、反撃のチャンスが生まれる。
- **守って、決める。** 紙風船を守る緊張感と、一撃を決める達成感を味わう。

## 4つの場面

1. **構える。** 紙風船を守る位置で向き合い、音や光の合図を待つ。
2. **剣を交える。** 合図に合わせて剣を受ける。成功音と「受けた！」で手応えを返す。
3. **隙ができる。** ロボットの剣が後退し、3つの弱点から1つがランダムに光る。
4. **一撃を決める。** 光る弱点へ移動し、点灯中に叩く。1ダメージを与え、次の応酬へ戻る。

## 基本ルール【原案】

- 人の弱点は紙風船1つ。ロボットが狙ってくるので、剣で受けて守る。
- 受け成功1回につき、反撃のチャンスが1回生まれる。
- 点灯中の弱点への有効な命中で1ダメージ。ロボットのHPは3、合計3回の命中で勝利。
- 紙風船を割られたら敗北。
- 1ダメージを与えるごとに難易度が上がる、3段階の展開をつくる。

## 今回、合意したいこと

**「剣を交える手応え」を中心に、〈合図に合わせて受ける → 光る弱点へ移動 → 一撃を決める〉体験の試作を進めたい。**

まず人がロボット役を演じ、剣の応酬が楽しいか、合図で行動できるか、弱点への移動が気持ちよくつながるかを確かめます。

原案の難易度上昇と移動は残しつつ、最初は数歩の移動と点灯時間の調整で試します。ロボット速度の上昇を必須条件とせず、合図や判定の幅も調整候補にします。

## 実機で確認すること

- 自動動作、後ずさり、ターゲット攻撃の時間をどう切り替えるか。
- 音・光と打ち合いをどう合わせ、カメラ情報から誰が成功を判定するか。
- ターゲット命中と紙風船の破損をどう検出するか。

基本ルールの採用と、実機で実現できる動作・判定は分けて確認します。
