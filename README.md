# ロボットと、チャンバラ。

「ロボットとチャンバラできた」を目指す展示の画面ラフです。剣の認識からゲーム開始、打ち合い、勝敗までをモックで試せます。

## 起動

Node.js 22.18以降を用意して、プロジェクト直下で実行します。

```sh
npm ci
npm run dev
```

表示先：<http://127.0.0.1:5173>

React / TypeScript / Vite / CSS。依存バージョンは `package-lock.json` に固定しています。

## 始め方

- 最初の画面で「プレイ画面」または「管理者画面」を選びます。
- 選択すると、それぞれ `#/play`、`#/admin` へ遷移します。
- プレイ画面では、剣が未認識の間は「ゲーム開始」を押せません。
- 下部のモック操作で「剣を認識させる」を押すと、認識済みの表示に変わり、開始できます。「認識を解除」で開始不可に戻ります。
- 「ゲーム開始」で `#/play/countdown` へ進み、「3・2・1」を各1秒、「スタート！」を0.6秒表示してから `#/play/game` へ自動で進みます。
- カウントダウン中に「プレイの準備に戻る」やブラウザーの戻る操作で離れると、カウントダウンを中止します。
- プレイの準備に戻った場合や再読み込みした場合は、再び認識が必要です。カウントダウン・ゲーム画面への直リンクも、準備画面へ戻します。

管理者画面は、まだ見出しだけです。カメラ・ROS・物理ライトには接続していません。カメラの使用許可も求めず、ボタン操作だけで認識を再現します。

## ゲームの試し方

ゲーム画面に入ると60秒の計測が始まります。左上に残り時間、右上にロボットのHP、中央に今すること、下部に赤・青・黄の3灯を表示します。残り10秒から時間を強調します。ライトの並びは実物と対応させる想定です。

操作役が打ち合いを見て、キーまたは画面内のモックボタンで出来事を入力します。

| キー | 操作 |
| --- | --- |
| `A` | 次の打ち合いを始める |
| `Space` | 剣を受けることに成功 |
| `1` / `2` / `3` | 赤 / 青 / 黄の弱点を叩く |
| `F` | 剣を受けることに失敗 |
| `B` | 紙風船が破損した |
| `Esc` | 一時停止 / 再開 |

最初は「剣で受けて！」から始まります。受けに成功すると「受けた！」を0.9秒表示し、ランダムな1灯が光って攻撃チャンスになります。光っている弱点への命中でHPが1減り、合計3回の命中で勝利です。暗いライトや時間外の入力は得点になりません。

点灯時間は仮に8秒・6秒・4秒とし、有効な命中ごとに短くなります。命中またはチャンス切れの表示を0.9秒挟んで「次に備えよう」へ戻り、`A`で次の打ち合いを始めます。受け失敗だけでは敗北になりません。

紙風船の破損で敗北、60秒経過で時間切れです。勝敗・時間切れで進行を終了し、一時停止中は残り時間・点灯時間・演出・音を止めます。

BGMと合図・受け・命中の音は、自作の合成音による仮素材です。最初は音ONで、画面の音ON/OFFで切り替えられます。実際の剣の検出や、音楽に対するタイミング判定はまだ行いません。

敗北時（紙風船の破損）は `public/audio/lose.mp3` を1回再生します。ゲーム開始時に読み込み、音OFFでは消音、画面を離れると停止します。ファイルの読み込みに失敗した場合は仮の敗北音を使用します。音源を差し替えた場合はブラウザーを再読み込みしてください。時間切れの音は別の仮素材です。
